# Murrieta · Правовая база гос. структур

Справочник по законодательству штата San Andreas и правилам проекта **GTA 5 RP**
для сотрудников государственных структур сервера **Murrieta (Сервер №20)**.

Статический сайт (GitHub Pages) + ИИ-помощник через Cloudflare Worker.

## Как работает ИИ-помощник

Ключ OpenRouter **нельзя** класть в статический сайт — его моментально достанут из исходников.
Поэтому:

```
браузер                          Cloudflare Worker            OpenRouter
───────                          ─────────────────            ──────────
1. ищет 8 нужных фрагментов
   по 1025 чанкам (BM25)
2. шлёт вопрос + фрагменты  ──▶  3. проверяет Origin
                                    и лимит 20 запр./мин
                                 4. добавляет ключ       ──▶  5. отвечает потоком
6. рисует ответ по мере      ◀──────────────────────────────  (SSE)
   поступления
```

Поиск по базе идёт **в браузере**, поэтому модель получает не всю законку, а ~5 КБ
релевантных выдержек. Это и дёшево, и заметно точнее.

## Модель и стоимость

По умолчанию — `qwen/qwen3.7-flash`: дёшево, 1M контекста, хорошо понимает русский.

**Расход на один вопрос:** ~4 000 входных токенов (системный промпт + 8 фрагментов +
история) и ~400 выходных.

| `deepseek/deepseek-v4-flash-0731` | 0.090 | 0.180 | ~$0.00043 | ~$0.43 | ~$4.30 |
| `google/gemini-2.5-flash-lite` | 0.100 | 0.400 | ~$0.00056 | ~$0.56 | ~$5.60 |
| `openai/gpt-5-nano` | 0.050 | 0.400 | ~$0.00036 | ~$0.36 | ~$3.60 |

Цены с OpenRouter на 04.08.2026. Если ответы будут слишком поверхностными —
переключитесь на `deepseek/deepseek-v4-flash-0731`, разница в деньгах копеечная.

**Хостинг бесплатный:** GitHub Pages без ограничений по трафику для таких объёмов,
Cloudflare Workers — 100 000 запросов в сутки на free-плане.

Рычаги на стоимость: `MAX_TOKENS` в `wrangler.toml` (потолок ответа) и число
фрагментов в `ai.js` (`retrieve(text, 8)`).

## Развёртывание

### 1. Сайт (GitHub Pages)

Уже настроено: `Settings → Pages → Source: Deploy from a branch → main / (root)`.
Файл `.nojekyll` нужен, чтобы Pages не игнорировал папки — не удаляйте.

### 2. Worker

```bash
cd worker
wrangler secret put OPENROUTER_KEY     # вставить ключ sk-or-v1-...
wrangler deploy
```

Затем в `wrangler.toml` пропишите свой адрес сайта:

```toml
ALLOWED_ORIGINS = "https://ВАШ-НИК.github.io"
```

и задеплойте ещё раз. Без этого Worker вернёт 403 — так и задумано, чтобы вашим
ключом не пользовались посторонние.

Адрес Worker вставляется в `assets/js/ai.js` (константа `WORKER_DEFAULT`) либо
прямо на странице — кнопка «Настроить» в чате сохранит его в браузере.

### 3. Свой домен

**GitHub Pages:** `Settings → Pages → Custom domain`, у регистратора — запись
`CNAME` на `ВАШ-НИК.github.io`. Файл `CNAME` в корне создастся сам.

После смены домена обновите `ALLOWED_ORIGINS` в `wrangler.toml` и передеплойте Worker.

## Обновление данных

Форум живой — правила меняются. Тексты собраны скриптом через браузер
(Cloudflare блокирует обычные запросы), сырые файлы лежат вне репозитория.

Чтобы пересобрать `data/` из сырых текстов:

```bash
python3 tools/build.py
```

Скрипт ждёт папку `raw/` рядом с собой и кладёт результат в `data/`.
