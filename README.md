# Murrieta · Правовая база гос. структур

Справочник по законодательству штата San Andreas и правилам проекта **GTA 5 RP**
для сотрудников государственных структур сервера **Murrieta (Сервер №20)**.

Статический сайт (GitHub Pages) + ИИ-помощник через Cloudflare Worker.

## Как работает ИИ-помощник

Ключ OpenRouter лежит в секретах Cloudflare (`wrangler secret`) и в браузер не попадает.
Класть его в статический сайт **нельзя** — его моментально достанут из исходников. Поэтому:

```
браузер                          Cloudflare Worker            OpenRouter
───────                          ─────────────────            ──────────
1. ищет 8 нужных фрагментов
   по 1014 чанкам (BM25)
2. шлёт вопрос + фрагменты  ──▶  3. проверяет Origin
                                    и лимит 20 запр./мин
                                 4. добавляет ключ       ──▶  5. отвечает потоком
6. рисует ответ по мере      ◀──────────────────────────────  (SSE)
   поступления
```

Поиск по базе идёт **в браузере**, поэтому модель получает не всю законку, а ~5 КБ
релевантных выдержек. Это и дёшево, и заметно точнее.

## Модель и стоимость

Основная — `google/gemini-2.5-flash-lite`. Если её провайдер недоступен, OpenRouter
сам переходит к резервным из `FALLBACK_MODELS`.

**Расход на один вопрос:** ~4 000 входных токенов (системный промпт + 8 фрагментов +
история) и ~400 выходных.

| Модель | $/1M вход | $/1M выход | 1 вопрос | 1 000 вопросов | 10 000 вопросов |
|---|---|---|---|---|---|
| **`google/gemini-2.5-flash-lite`** ← основная | 0.100 | 0.400 | ~$0.00056 | **~$0.56** | ~$5.60 |
| `deepseek/deepseek-v4-flash-0731` ← резерв | 0.090 | 0.180 | ~$0.00043 | ~$0.43 | ~$4.30 |
| `mistralai/mistral-small-3.2-24b` ← резерв | 0.075 | 0.200 | ~$0.00038 | ~$0.38 | ~$3.80 |
| `qwen/qwen3.7-flash` | 0.030 | 0.130 | ~$0.00017 | ~$0.17 | ~$1.70 |

Цены с OpenRouter на 04.08.2026.

### Почему не самая дешёвая модель

`qwen/qwen3.7-flash` втрое дешевле, но на практике не подошла:

1. Это **reasoning-модель** — она стримит «размышления» в `delta.reasoning`, а `content`
   остаётся пустым, пока не исчерпается `max_tokens`. Ответ в чат не приходит вообще.
   Лечится параметром `reasoning: { enabled: false }` — он уже стоит в `worker.js`.
2. Её провайдер (Alibaba) регулярно отдаёт **429 rate-limited upstream**. Для справочника,
   которым пользуются во время задержания, это неприемлемо.

Оставлена в таблице как вариант: если бюджет станет важнее стабильности, поменяйте
`MODEL` в `wrangler.toml` и передеплойте.

**Хостинг бесплатный:** GitHub Pages без ограничений по трафику для таких объёмов,
Cloudflare Workers — 100 000 запросов в сутки на free-плане.

Рычаги на стоимость: `MAX_TOKENS` в `wrangler.toml` (потолок ответа) и число
фрагментов в `ai.js` (`retrieve(text, 8)`).

## Развёртывание

### 1. Сайт (GitHub Pages)

Уже настроено: `Settings → Pages → Source: Deploy from a branch → main / (root)`.
Файл `.nojekyll` нужен, чтобы Pages не игнорировал папки — не удаляйте.

### 2. Worker

```bash
cd worker
wrangler secret put OPENROUTER_KEY     # вставить ключ sk-or-v1-...
wrangler deploy
```

Затем в `wrangler.toml` пропишите свой адрес сайта:

```toml
ALLOWED_ORIGINS = "https://ВАШ-НИК.github.io"
```

и задеплойте ещё раз. Без этого Worker вернёт 403 — так и задумано, чтобы вашим
ключом не пользовались посторонние.

Worker уже развёрнут: `https://murrieta-ai.realfactchecknews.workers.dev`.
Адрес прописан в `assets/js/ai.js` (константа `WORKER_DEFAULT`); его можно поменять
прямо на странице — кнопка «Настроить» в чате сохранит его в браузере.

### 3. Свой домен

**GitHub Pages:** `Settings → Pages → Custom domain`, у регистратора — запись
`CNAME` на `ВАШ-НИК.github.io`. Файл `CNAME` в корне создастся сам.

После смены домена обновите `ALLOWED_ORIGINS` в `wrangler.toml` и передеплойте Worker.

## Обновление данных

Форум живой — правила меняются. Тексты собраны скриптом через браузер
(Cloudflare блокирует обычные запросы), сырые файлы лежат вне репозитория.

Чтобы пересобрать `data/` из сырых текстов:

```bash
python3 tools/build.py
```

Скрипт ждёт папку `raw/` рядом с собой и кладёт результат в `data/`.

## Важно

Это **неофициальный** справочник. При любом расхождении приоритет за форумом —
на каждой странице есть ссылка на первоисточник. Поддержка памятки из Discord,
на которую многие ориентируются, прекращена 02.07.2025; раздел «Расхождения»
показывает, где она уже неверна.
